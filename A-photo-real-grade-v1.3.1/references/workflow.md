# Workflow

## User-package stage contract

In combined-user generation, the base stage is normal A for a scene or normal C for a portrait, followed by required strong B unless the current user explicitly says grading-only/no-design or requests a lower B strength. Keep the caller's contract throughout local routing. Base QC concerns the photographic master; it does not prohibit B page layout or certify the entire final deliverable. Preserve person/scene identity in B; do not repaint the person to fit a page. Standalone photographic workflows remain standalone.

## 1. Source diagnosis
Record: source light direction, plausible key light, brightest real surface, darkest textured area, depth layers, dominant color families, and any elements that must remain exact.

## 2. Minimal correction
Correct exposure/white balance only as much as needed. Avoid the temptation to "wake up" every dark region.

## 3. Local hierarchy
Use existing geometry, shadows, reflections, foliage gaps, water sheen, windows, pavement, or sky gradients to guide the eye. Do not fabricate new lighting geometry.

## 4. Color
Prefer selective/local color relationships. Keep object colors believable. Avoid global single-color veils and excessive saturation.

## 5. Texture and realism
Preserve natural edges and material texture. Do not create AI-like hyperdetail, smeared foliage, redrawn water, synthetic masonry, or plastic people.

## 6. Authenticity check
The final should plausibly be obtainable from the same RAW/JPEG with skilled photographic post-processing. If it reads as a new scene, the edit is too strong.
