# Routing and completion regression cases

Documented expected behavior; static policy checks do not substitute for generated-image inspection.

| Case | Expected |
|---|---|
| Scene, process with package | normal A + strong B |
| Close selfie, process with package | normal C + strong B |
| Night back-view full-body, natural hair/slimming | normal C + authorized extras + strong B |
| Landscape with incidental walkers | normal A + strong B |
| Only color correction, no design | A or C by main subject; B off |
| Keep photo natural; no other restriction | normal A/C + strong B, source preserved |
| Explicit light B | normal A/C + light B, activation floor applies |
| Explicit standard B | normal A/C + standard B |
| Explicit design only/no grade | B only, strong unless overridden |
| No text | strong B via non-text page/graphic hierarchy |
| Feedback/diagnosis only | no generation |
| Standalone A/C | original photographic workflow, no compulsory B |
| T0 + PRESERVE + strong B | valid; protect rendering and build strong page |
| Weak confidence or already excellent photo | safer source treatment, keep strong design |
| Batch breath/photo-led role | low visual noise, strong page still required |
| Grade + border + tiny caption | R04_UNDER_DESIGNED, not done |
| Strong layout but altered portrait identity | source gate fails, not done |
| Base complete, B not executed | pending B, not done |
| Tool failure / retry ceiling | blocked; truthfully report incomplete stages |
| All photos requested | no automatic culling or substitutions |
