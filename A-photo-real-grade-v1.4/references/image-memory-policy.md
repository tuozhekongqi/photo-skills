# Image Memory Policy — A

The distributable A skill is intentionally lightweight.

## Keep as images
- **Positive**: only explicit user-approved results that teach a distinct, reusable visual principle.
- **Cautionary**: only a tiny set of archetypal failures that are easier to understand visually than in prose.

## Convert to text, then delete the image
- “还行” / partial approval;
- “一般” / needs improvement;
- tutorial screenshots;
- broad research/reference scraping;
- duplicate examples of the same lesson;
- old experiments once their useful lesson is written into the skill.

## Hard limits
- No secondary image library.
- No teaching-screenshot archive.
- No mixed research-photo archive.
- Do not retain an image merely because it was discussed.

The goal is **small package, high signal**: pictures demonstrate only the strongest positive targets and a few representative failure archetypes; the detailed learning lives in text.
