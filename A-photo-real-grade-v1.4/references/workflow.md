# Workflow — minimal-necessary A grade

## 1. Need test
First ask internally: **does this photo actually need editing?**

If the source already feels balanced, keep it near-original. “No meaningful change” is a valid outcome.

## 2. Minimal correction
Correct only the specific problems that matter: exposure, white balance, highlight control, shadow readability, distracting local color, or minor geometry/lens issues.

Do not “wake up” every dark area. Do not search for more saturation, more clarity, more dehaze, or more cinematic color merely because they are available.

## 3. Local hierarchy
If local work is needed, use existing geometry, real light, shadows, reflections, foliage gaps, water sheen, windows, pavement, or sky gradients to guide the eye. Do not fabricate lighting geometry.

## 4. Color
Prefer selective/local color correction. Preserve believable object colors and the scene's original color relationship. Avoid global single-color veils, saturation inflation, or reinterpreting neutral weather as golden hour.

## 5. Texture
Preserve natural edges and real material texture. Sharpen/clarify only where source detail supports it. Protect sky, water, foliage, skin, masonry, signage, and fine architecture from AI-like hyperdetail or plastic smoothing.

## 6. Authenticity check
The final should plausibly be obtainable from the same RAW/JPEG with skilled photographic post-processing. If the first impression is “filter / relight / AI repaint” rather than “the same photo, carefully finished,” back off.
