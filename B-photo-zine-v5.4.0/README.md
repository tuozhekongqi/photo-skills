# Photo Zine Social v5.4.0 — strong-design user runtime

A source-first visual-design skill for turning real travel, architecture, street, landscape, garden, detail, and documentary photos into varied Photo Zine outputs.

## Runtime principle
Understand the source first. Default to strong page construction while preserving the photograph. Photographic restraint and design strength are independent; follow references/delivery-contract.md. B may redesign the page but must preserve person/scene identity.

## Image library
- `reference-library/positive/` — user-approved strong references.
- `reference-library/cautionary/` — tiny archetypal failure set only; not a general negative gallery.

There is no secondary image library and no research-image archive in this runtime package. “还行 / 一般 / negative / tutorial” knowledge is stored as text under `references/`. This prevents the package from becoming large and prevents old examples from becoming accidental templates.

## Golden backup
No nested golden-backup ZIP is shipped here. This revision preserves the user-provided original combined ZIP as rollback material; it does not verify the location or availability of any separately named historical golden ZIP.

## Key feedback files
- `references/feedback-loop.md` — evaluation-mode protocol.
- `references/feedback-ledger.md` — distilled user ratings and current design corrections.
- `references/reference-index.md` — retained positive image references and why they matter.
- `references/research-notes.md` — textual lessons extracted from deleted research images and external design research.
