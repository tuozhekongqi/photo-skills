# Image Memory Policy — B

The distributable B skill is intentionally lightweight.

## Keep as images
- **Positive**: explicit strong references and user-approved outputs that add a distinct layout/style behavior.
- **Cautionary**: at most a very small set of archetypal failures; one example is enough when many failures share the same cause.

## Convert to text, then delete the image
- “还行” / partial approval;
- “一般” / needs improvement;
- tutorial screenshots;
- research-only design examples after their principles are extracted;
- repeated examples of the same template failure.

## Hard limits
- No secondary image library.
- No research-image archive in the runtime package.
- No screenshot dump.
- A liked page may enter the positive library, but its visible template must not become mandatory.

The goal is **small package, high signal**: images show strong design behaviors; nuanced feedback and avoidance knowledge live primarily in text.
