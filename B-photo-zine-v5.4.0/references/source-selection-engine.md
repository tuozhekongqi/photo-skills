# Source Selection Engine v5.2

## Delivery-contract scope

Read `delivery-contract.md` first. Source culling is allowed only when the user permits selection, not when every photo is requested. C0/no text does not cancel strong B: build non-text page hierarchy. Keep entry context, route, source_id and design strength stable.

The best series is not created by styling every uploaded photo. Selection happens before styling.

The selector removes two different kinds of redundancy:
1. **near-duplicate redundancy** — almost the same angle / frame;
2. **visual-story redundancy** — technically different frames that still communicate the same thing in the same way.

---

## 1. Source quality profile

Score each source 0-3 on:
- composition;
- light;
- clarity;
- subject scale;
- obstruction / reflection control;
- negative-space usefulness;
- emotional timing;
- visual uniqueness inside the batch.

Record one `selection_strength` sentence such as:
- `best cloud + wall relationship in this angle group`;
- `only frame where the cable cars create strong directional depth`;
- `weaker duplicate with heavy window reflection`.

---

## 2. Angle groups

Create angle groups when photos share most of:
- camera position;
- viewing direction;
- focal length / crop;
- subject arrangement;
- light;
- visual purpose.

From each group, normally keep 1 strong representative.

Keep 2 only when the two frames have genuinely different visual behavior, for example:
- one is about cloud / negative space;
- another is about geometry / movement;
- one is horizontal, another vertical and compositionally distinct.

---

## 3. Visual-story groups

After angle deduplication, cluster sources by the story they tell, not only their viewpoint.

Example story groups:
- `vast mountain + sky`;
- `wall as winding line`;
- `cable-car movement`;
- `arrival / destination marker`;
- `crowd / human travel energy`;
- `architectural detail`.

If a batch contains four technically different photos that all function as `vast mountain + sky`, keep the strongest 1-2 unless the user explicitly wants a comprehensive record.

---

## 4. Selection score

A useful planning score is:

- source quality: 40%
- visual-behavior uniqueness: 25%
- series coverage value: 20%
- style opportunity: 10%
- personal / narrative value: 5%

Penalize:
- heavy reflection / obstruction;
- unclear focal point;
- redundant visual story;
- weak technical quality when a better equivalent exists.

This score is used for **selection**, not style choice.

---

## 5. Coverage rule

For a typical social-media travel set, prefer a smaller set that covers different behaviors:
- establishing / destination view;
- movement / journey;
- quiet atmosphere;
- cultural / material detail;
- human-scale memory;
- one conceptual surprise if supported.

Do not force all categories. Use what the sources actually provide.

---

## 6. Skip semantics

Use:
- `skipped-near-duplicate` — same angle / composition has a stronger representative;
- `skipped-visual-redundancy` — different frame but same visual story is already covered more strongly;
- `skipped-low-value` — weak composition / obstruction / low unique value;
- `reserved-alt` — strong alternative not currently selected, useful if another selected frame fails.

Never silently discard a source.
