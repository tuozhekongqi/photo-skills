# Evaluation Protocol v5.1 — Lightweight Final QC

Use this as a compact final check. It must not become a heavyweight per-image pre-generation audit or a quota generator.

## A. Source fidelity
Reject/redo if any occurs:
- wrong source or source substitution;
- major subject/landmark identity lost;
- invented weather/light/objects that contradict the source;
- design layer obscures or cuts through the key subject without a clear reason.

## B. Treatment restraint
Check only the dimensions actually used:
- color/contrast not visibly overdone;
- typography remains subordinate;
- material/paper/collage does not become the subject;
- conceptual treatment remains source-derived;
- a recent user comment has not been overgeneralized into a global style shift.

## C. Batch check
No family count, layout count, intensity rhythm, or experimental slot is required.

At the end verify:
- no accidental omissions/substitutions;
- no forced variety that weakens strong photos;
- any collage has a real source relationship and does not swallow the batch;
- **no unintended nine-grid / grid-mosaic photo output**. If one appears, invalidate and rebuild the batch.

## D. Redo diagnosis codes
- `R01_WRONG_SOURCE`
- `R02_SOURCE_IDENTITY_LOST`
- `R03_OVER_DESIGNED`
- `R04_UNDER_DESIGNED`
- `R05_TEMPLATE_REPEAT`
- `R06_BAD_TYPE_PLACEMENT`
- `R07_COPY_GENERIC`
- `R08_CONCEPT_FORCED`
- `R09_PALETTE_DRIFT`
- `R10_LAYOUT_MISMATCH`
- `R11_UNRELATED_INVENTION`
- `R12_MULTI_SOURCE_MERGE`
- `R13_FEEDBACK_OVERFIT`
- `R14_GRID_MOSAIC_FAILURE`

On redo, change the actual cause and keep successful decisions intact.
