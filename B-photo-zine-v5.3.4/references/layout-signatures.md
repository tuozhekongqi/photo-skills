# Layout Signatures v5.1

Layout signatures are a source-led toolbox, not a diversity quota. Use a layout only when it helps the current photograph.

## Core signatures
- `FULL_BLEED_QUIET` — full image, minimal or no text.
- `FULL_BLEED_CAPTION` — full image with one restrained caption block.
- `WHITE_FIELD_PLATE` — framed image on white / ivory field.
- `TOP_PHOTO_BOTTOM_PAPER` — photo above, editorial paper space below.
- `TICKET_DIPTYCH` — one photo + one small collectible ticket/design object; not a multi-photo diptych.
- `APERTURE` — one source photo visible through one source-inspired paper aperture.
- `HERO_PLUS_MICROCROP` — one hero image plus 1–2 analytical crops from the **same source**.
- `ASYMMETRIC_EDITORIAL` — one photo and text share an asymmetrical editorial alignment system; “grid” here means design alignment, not a multi-photo grid.
- `EDGE_TRANSITION` — one source-derived transition from photo to print/paint.
- `CENTERED_SPECIMEN` — detail centered as an archival / collectible object.
- `GRAPHIC_FIELD` — one hero image/crop with 1–2 flat graphic planes.

## Repetition control
Repetition control is a soft check. If several sources genuinely support the same signature, repetition is acceptable. Change layout only when another option is equally strong for the source.

Do not use nine-grid, grid-mosaic, contact-sheet, filmstrip, or multi-photo dumping as a layout shortcut.

## Selection rule
Choose from the photograph's geometry and available negative space. Do not choose a layout merely to make a batch look more varied.
