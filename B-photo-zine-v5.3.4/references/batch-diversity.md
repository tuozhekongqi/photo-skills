# Batch Context & Same-Source Series v5.3.4

## Purpose
Treat a batch as one project for coherence, but do not turn diversity into a quota or collage into a shortcut. The user's photographs remain primary.

## 1. Batch handling
When a user submits a batch, process it as a batch in upload order. Do not make a heavyweight per-image curation/audition pass the dominant workflow. Use only lightweight internal bookkeeping needed to avoid source mistakes and repetition.

Different viewpoints should normally remain available even if they tell a similar story. Only truly near-identical frames may be collapsed when clearly redundant under the existing near-duplicate allowance.

## 2. No diversity floors
There is no required number of style families, layout signatures, experimental branches, or multi-image pieces.

Diversity is useful only when two treatments are similarly suitable. It must never override:
1. source fidelity;
2. the strongest existing behavior of the photo;
3. a clearly approved user baseline.

## 3. Multi-image composition is an exception
Multi-image work is allowed only when complementary images of the same subject/story genuinely become stronger together. It is not a batch-consumption mechanism.

Good candidates:
- restrained diptych;
- restrained triptych;
- asymmetric one-hero + one/two small supporting frames;
- same-subject sequence where each frame contributes a different visual idea.

Do not use:
- nine-grid;
- grid-mosaic photo sheets;
- contact-sheet/film-strip layouts used merely to fit many uploads;
- collage that covers, cuts through, or competes with the primary subject;
- collage used only because the batch is large.

A carefully shot source should not be sacrificed or hidden merely to become a supporting panel.

## 4. Experimental branches
Watercolor, ink-wash, print/halftone, Second World, archival, analog, or other stylization are optional tools. Use them only when the source strongly supports them or the user requests them. A large batch is **not** itself a reason to experiment.

## 5. Preserve strong photography
Strong non-portrait photographs remain under the default A+B route. A may stay near-original and B may be extremely restrained or near-no-op. Multiple strong photographs may legitimately share the same broad treatment if that is what fits them best. Do not create visible design merely to prove that B was used, and do not force a worse style just to create a visually diverse contact sheet.

## 6. Final batch check
At the end, do one light check:
- source identities preserved;
- no accidental omissions/substitutions;
- no over-processing caused by trying to make outputs different;
- any collage has a clear compositional reason and keeps the subject dominant;
- no unintended nine-grid / grid-mosaic output.

If a nine-grid or grid-mosaic photo layout appears, invalidate and rebuild the batch. This is a final hard-failure check, not a style-selection priority.
