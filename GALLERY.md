# 参考图库总览 · Reference Library Gallery

本页展示 Photo Skills 内置参考图库（reference-library）全部 **45 张**图片——它们是 A / B 模块运行时的**风格与质量参照**（visual-memory assets，非可复制模板）。

- **正向参考（positive）**：示范「什么方向是成立的」；
- **反例（cautionary）**：示范「什么失效模式要避免」——模板过拟合、场景重绘、过度清理等。

> 图片已通过公开上传审查；移出清单与原因见 [PUBLIC_ASSET_REVIEW.md](PUBLIC_ASSET_REVIEW.md)。全库图片无 EXIF 元数据。
