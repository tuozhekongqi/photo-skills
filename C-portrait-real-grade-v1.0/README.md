# C — Portrait Real Grade v1.0

C is the portrait-specific realism layer in the combined Photo Skills package.

Default routing:
- clear portrait/person subject: **A + B + C**;
- no portrait/person subject: **A + B**;
- explicit user instructions override defaults.

C protects identity, natural face geometry, skin texture, hair realism, anatomy, and person-specific lighting. It is intentionally low-strength by default.
