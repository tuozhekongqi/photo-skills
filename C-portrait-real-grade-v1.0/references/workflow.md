# Portrait workflow

1. Confirm that the person is actually a subject, not merely incidental background presence.
2. Preserve identity/pose/expression first.
3. Let A establish the scene and light field.
4. Keep C active by default when the person is a clear subject. Apply visible person-specific corrections only when they materially help; otherwise let C remain near-no-op while still protecting identity, anatomy, skin texture, face contours, hair, clothing response, and person-scene light consistency.
5. Let B add restrained presentation without covering or overpowering the person.
6. Compare against the source: if face/body/hair/clothing/background geometry appears rewritten, reduce strength.
7. Treat user-requested extras (hair smoothing, slight slimming, etc.) as additive local instructions, never as replacements for the realism baseline.
