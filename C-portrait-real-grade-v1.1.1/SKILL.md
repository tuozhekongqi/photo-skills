# Portrait Real Grade Skill

## Combined user-package integration

When called by the combined ABC user package for a portrait edit, the default route is C+B with normal C and strong B. Preserve the caller's locked route and design strength throughout Step 1 and final QC. Finish the portrait master, mark base_done, then hand it to B; C-only is not the final package deliverable unless the user explicitly requested only photographic work. Hair/body extras are additive to normal C and do not cancel B. Standalone C retains C-only photographic finishing; shaping requires explicit authorization. Source-composition constraints protect the master/person, not B's page layout.

Use this skill when **the person is the main subject** and the user wants the same person and same moment to look better, more cinematic, more atmospheric, or more finished while remaining recognizably the original photograph.

The governing principle is:

> **Person first. Atmosphere second. Design last.**

C is not a beauty-generator and not a portrait-redraw system. It is a **source-preserving portrait grade**.

## Priority / weight neutrality
Newly added techniques do **not** receive extra priority merely because they are new. Treat them as modular tools at the same normal weight as the rest of C.

Priority remains:
1. source truth and identity;
2. user intent for this image;
3. C's existing photographic hierarchy / light / environment rules;
4. only then the specific retouch module that is relevant.

A new module must not dominate an edit when the image does not need it. Whole-person shaping, face retouch, hair cleanup, clothing cleanup, cinematic grading, and depth treatment are **conditional retouch modules**, not mandatory effects. B integration is determined separately by the locked delivery route; in combined-user C+B it is required.

**User extra requests are additive, not substitutive.** If the user asks for something like smoother hair or a slimmer waist, still run the appropriate C workflow first; then apply the extra request on top. Do not skip C just because an extra request is explicit.

## Routing rule
Use C when the image is primarily:
- selfie / close portrait;
- headshot / half-body / full-body portrait;
- back-view portrait;
- environmental portrait where the surrounding scene matters but the person remains the narrative center;
- couple / group portrait where people are the intended subject;
- night portrait, campus portrait, street portrait, travel portrait, lifestyle portrait, or cinematic human moment.

Do **not** use C merely because people appear in frame. If people are incidental scale/life elements and the scene itself is the subject, use A.

For a combined-user generation request, default to **C+B**, even without magazine/collage keywords; use normal C then strong B. In standalone C, add B when editorial design is requested. An explicit grading-only/no-design instruction selects C-only.

## Non-negotiable constraints
1. **Identity lock.** Preserve the same person: facial geometry, recognizable asymmetry, body proportions, pose, hands, hairline/hair mass, clothing, accessories, and viewpoint.
2. **No body/face redesign unless explicitly requested.** Do not enlarge eyes, slim the face/body, change nose/jaw, lengthen legs, rewrite hair, change clothing, or invent makeup.
3. **No synthetic subject relighting.** Do not paint a rim light, halo, studio key light, beauty light, spotlight, or glow that the source scene cannot support.
4. **Subject prominence must come from relationships, not cutout effects.** Use restrained local exposure, tonal hierarchy, color separation, texture, and depth to help the person read first.
5. **Soft-mask rule.** Any subject/background separation must transition softly. No bright contour around hair, shoulders, arms, or legs; no obvious selection edge.
6. **Skin remains skin.** Preserve pores, fine texture, natural unevenness, and facial dimensionality. Remove or reduce only distracting temporary defects when appropriate; do not flatten the face into plastic.
7. **Night light must remain night light.** Practical lamps should feel soft, localized, and naturally scattered. Avoid hard yellow patches, wall over-brightening, excessive bloom, orange halos, or fake studio illumination.
8. **Depth is gradual.** Nearby environment should retain structure; midground may soften; distant lights/background may blur more. Do not blur everything outside the person equally.
9. **Cinematic color cannot sacrifice believable skin or source color.** Prefer low-intensity tonal separation over a global teal/orange wash.
10. **C output is a master portrait.** In C+B, B may design the page but must not casually re-render, re-pose, or re-identify the person.

# Whole-person retouch extension

C is not limited to the face. When the whole person is visible, evaluate the person as coordinated subregions before grading:
- face / skin / facial structure;
- hair;
- neck / shoulders / torso;
- waist / hips / limbs / stance;
- hands;
- clothing and fabric drape;
- subject light;
- surrounding environment.

These are **independent adjustment targets**, not invitations to redesign anatomy. The goal is to make the existing person read better while preserving identity, perspective, pose, and believable human structure.

### Structural lock before retouch
Before changing anything, mark mentally what must not drift: facial geometry, nose bridge/root/nostrils, eye spacing, mouth shape, jaw, shoulder width, limb attachment, hand count/shape, pelvis position, leg length, clothing seams, and camera perspective. If a requested adjustment can be achieved through light, fabric, posture cues, or local tone, prefer those before geometric deformation.

### Body shaping / slimming
Only when explicitly requested or clearly allowed by the active user preference:
1. start with clothing silhouette and fabric drape;
2. use local light/shadow to clarify body contour;
3. refine separation between torso, waist, skirt/trousers, and legs;
4. only then use a very small local contour deformation if needed;
5. protect straight background geometry near the body from warping.

A successful slim edit should be **noticeable but not conspicuous**. Do not lengthen limbs, collapse ribcage/pelvis anatomy, create impossible waist curvature, or bend walls/railings/doorframes.

### Face retouch
Treat face work primarily as local tone/color/texture correction, not face generation. Keep nose, eyes, lips, jaw, and facial asymmetry structurally stable unless the user explicitly requests a change. Avoid globally brightening the whole face; preserve dimensional shadow and highlight rolloff.

### Hair retouch
For requests such as “smoother hair,” reduce distracting flyaways, improve major strand direction, recover natural dark-hair separation, and add only subtle believable sheen. Keep some natural irregularity. Do not replace the hairstyle or turn hair into a uniform glossy mass.

### Clothing retouch
Use clothing as part of whole-person shaping: folds, hem, side seams, drape, shoulder line, and tonal separation can improve silhouette more naturally than direct body warping. Preserve fabric identity and garment design.

### Pose / gesture
Small posture cleanup may be used only when it does not alter identity or the photographed moment. Large pose changes, limb repositioning, or regenerated hands belong outside normal C unless explicitly requested.

# The four-layer portrait model

The whole-person extension sits **inside** the existing four-layer model rather than replacing it. Every C edit should still think in four independent but coordinated layers.

## C1 — PERSON IDENTITY
Protect the person before styling.

Check:
- face shape / profile / eye spacing / nose / lips when visible;
- shoulder width, torso, limbs, hand position, stance;
- hair silhouette, density, flyaways, parting, and length;
- clothing shape, fabric folds, logos/details, socks/shoes/accessories;
- pose and camera perspective.

If any of these look newly generated rather than edited, the edit has failed even if the color is attractive.

## C2 — SUBJECT LIGHT & TONAL HIERARCHY
Make the person easier to read without making them glow.

Preferred tools/logic:
- subtle local midtone lift on the subject when needed;
- restrained shadow recovery where source detail exists;
- slight background darkening or contrast reduction when it helps hierarchy;
- dodge/burn-style shaping to reinforce existing form;
- soft feathered transitions.

Avoid:
- hard rim light;
- bright hair outline;
- full-body exposure lift that disconnects the person from the scene;
- whitening the shirt/skin until it becomes the brightest unrelated object.

## C3 — ENVIRONMENT, DEPTH & ATMOSPHERE
The environment supports the person rather than competing with them.

Use depth-aware treatment:
- foreground: preserve enough texture/structure to keep the frame believable;
- subject plane: highest useful clarity and attention;
- midground: slightly reduced detail/contrast when appropriate;
- far background: can soften more, especially points of light and distant structures.

For night scenes:
- preserve deep blacks with some texture;
- let practical lights roll off softly;
- allow realistic low-light noise/grain;
- keep warm practical light and cool ambient light separate when source-supported;
- do not brighten walls/roads merely to make the frame look expensive.

## C4 — COLOR, SKIN & TEXTURE
Color grading finishes the relationship established above.

Priority:
1. neutralize obvious color cast only where needed;
2. protect skin/face color locally;
3. shape shadows/midtones/highlights separately;
4. apply low-strength mood color;
5. texture/grain last.

For visible faces/skin:
- edit on local masks/layers;
- correct patchy color rather than globally homogenizing all skin;
- preserve lips, blush, hair, eyes, and clothing from skin-tone edits;
- avoid excessive clarity reduction and saturation uniformity.

For film/cinematic character:
- modest contrast curve;
- soft highlight rolloff;
- restrained shadow density;
- fine grain only when it improves cohesion;
- avoid heavy fake grain, faded-black preset clichés, or aggressive orange/teal.

# Required workflow

## Step 1 — Determine portrait priority
Ask internally: **If all graphics disappeared, is the image mainly about this person?**
- yes -> select C as the base; preserve the caller's C+B design contract in combined-user mode;
- no -> select the scene base/route according to the root router without dropping required B.

## Step 2 — Source diagnosis
Before editing, identify:
- portrait type: face / half-body / full-body / back-view / environmental / group;
- light source and direction;
- brightest practical light;
- face/skin visibility;
- subject-background tonal overlap;
- depth planes;
- distracting highlights or color patches;
- authenticity risks: hair edge, hands, clothing, face geometry, body proportions.

## Step 2.5 — Whole-person diagnostic (when more than the face is visible)
Check face, hair, shoulders, torso, waist/hips, arms, hands, legs, clothing, and stance separately. Decide which areas actually need intervention. Do not apply slimming, reshaping, smoothing, or posture correction by default.

If the user supplied an extra request, translate it into a local target while preserving the rest of the C workflow. Example: “hair smoother + waist slimmer” means C baseline and atmosphere first, then hair cleanup and a controlled waist/clothing pass—not an image-wide regeneration.

## Step 3 — Global baseline
Establish believable exposure and white balance first. Do not chase “cinematic” before the photograph is stable.

## Step 4 — Subject mask / person layer
Create or conceptually isolate the person. Refine hair and clothing edges. Use soft feathering/flow. Apply only the minimum local changes needed for hierarchy.

## Step 5 — Environment layer
Treat background separately. Reduce competing brightness, local saturation, clarity, or sharpness only where needed. Preserve spatial logic.

## Step 6 — Face / skin layer when visible
Use a separate face/skin pass. Correct tonal/color irregularities while preserving texture and facial shape. Do not let skin masks contaminate lips, hair, clothes, or background.

## Step 7 — Depth shaping
Only increase blur if the source plausibly supports it or the user explicitly wants a portrait-depth treatment. Blur must follow depth rather than a binary subject/background cutout.

## Step 8 — Atmosphere
For night: soften practical lights, retain realistic low-light texture, keep the scene dim, and avoid manufactured halos. For day: keep source direction and quality of light.

## Step 9 — Color grade
Grade shadows, midtones, and highlights separately at restrained saturation. Protect skin and key clothing colors. Prefer local complementary separation over global color casts.

## Step 10 — Texture and finish
Apply fine grain/noise/softness only at the end and only if it helps the image feel coherent and photographic.

## Step 11 — Identity + AI-artifact check
At 100% and fit-to-frame, check:
- same person?
- same pose and proportions?
- same hair/clothes/details?
- any bright selection edge?
- plastic skin?
- fake light?
- fake bokeh?
- background rewritten?
- night scene accidentally turned into studio lighting?

If yes to any failure, back off.

# C intensity modes

## C-LITE — Natural portrait finish
Use when source is already strong. Minimal local correction, natural skin, tiny hierarchy improvement, no obvious stylization.

## C-CINEMA — Cinematic portrait
Use when the user asks for film/atmosphere. Stronger tonal hierarchy, subtle color separation, gentle highlight rolloff, controlled depth, optional fine grain. Identity and source lighting remain locked.

## C-NIGHT — Low-light environmental portrait
Use for night street/campus/travel portraits. Keep the overall frame dark, lights soft, distant background naturally blurred, and subject separation subtle. The subject should feel easier to notice, not artificially lit.

# C+B integration contract

C+B is a two-stage pipeline:

1. **C builds the portrait master.** Identity, light, skin, depth, environment, and cinematic tone are resolved first.
2. **B designs around the master.** Typography, paper, collage, layout, crop, and narrative are secondary.

Rules for B after C:
- do not re-grade the portrait aggressively;
- do not generate a new lookalike person for an inset;
- if an inset includes the person, derive it from the same source/C master through a crop or alternate source from the same confirmed person/session;
- if person consistency cannot be guaranteed, use environment/details-only insets;
- graphic elements must not cover the face or destroy the portrait hierarchy unless the user explicitly wants that treatment;
- C remains the truth layer; B is the presentation layer.

# Evaluation / feedback mode
When the user is reviewing a prior portrait output, do not automatically generate unless requested. Diagnose the failure category:
- identity drift;
- body/pose drift;
- ineffective or overdone requested shaping (waist/body/hair);
- warped background geometry from body edits;
- skin/face over-retouch;
- synthetic lighting;
- poor subject/environment separation;
- depth/bokeh error;
- color-grade mismatch;
- design layer overpowering the person;
- inset/person mismatch in C+B.

Record transferable lessons in `references/feedback-ledger.md`. Keep image references only for explicit strong positives or unusually useful failure archetypes.
