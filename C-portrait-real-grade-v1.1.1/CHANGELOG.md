# Changelog

## 1.1.1 — 2026-10-05 user package

Add a locked normal-base/strong-B delivery contract. Separate photographic T from page strength; retain source/person protection and existing grade priority. Update routing, prompts, recovery, completion gates and examples. Normalize SKILL.md discovery metadata. Earlier entries below describe historical versions, not the current default contract.

## v1.1 — 2026-10-01
- Extended C from face-centric portrait finishing to whole-person retouch: face, hair, body, clothing, pose, light, and environment.
- Added structural-lock rules before any slimming/reshaping.
- Added body-shaping order: clothing/drape -> local light -> silhouette separation -> minimal local deformation.
- Added explicit hair and clothing retouch modules.
- Added “user extra requests are additive, not substitutive”: C workflow still runs before requests such as smoother hair or slimmer waist.
- Added priority/weight neutrality: new modules do not become dominant simply because they are newly added.
- Added QC for ineffective/overdone shaping and warped background geometry.


## v1.0 — 2026-09-30
- Added independent portrait-first C route.
- Added four-layer portrait model: identity, subject light, environment/depth, color/skin/texture.
- Added C-LITE, C-CINEMA, and C-NIGHT internal intensity modes.
- Added strict C+B contract: portrait master first, design second; no synthetic lookalike insets.
- Added research-derived rules for local masks, skin-tone protection, depth-aware blur, tonal-range color grading, film texture, and face-first attention.
- Added user-specific night portrait feedback: softer practical lights, natural distant blur, no rim-light AI look, environment-only inset preferred over mismatched person inset.
