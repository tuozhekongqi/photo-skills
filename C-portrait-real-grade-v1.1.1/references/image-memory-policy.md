# C image-memory policy

- Keep only explicit strong user-approved portrait references in `reference-library/positive/`.
- “还行 / 不错但…” feedback becomes text rules, not a permanent image target.
- Keep a cautionary image only when the visual failure cannot be conveyed clearly in text.
- Do not retain tutorial/research screenshots; extract lessons into `research-lessons.md` and delete the images.
- A positive portrait reference teaches principles, not a fixed preset or face transformation.
