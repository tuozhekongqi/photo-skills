# C + B integration

## User-package stage contract

In combined-user generation, the base stage is normal A for a scene or normal C for a portrait, followed by required strong B unless the current user explicitly says grading-only/no-design or requests a lower B strength. Keep the caller's contract throughout local routing. Base QC concerns the photographic master; it does not prohibit B page layout or certify the entire final deliverable. Preserve person/scene identity in B; do not repaint the person to fit a page. Standalone photographic workflows remain standalone.

## Pipeline
`SOURCE -> C portrait master -> B editorial/design layer`

C owns:
- person identity;
- face/skin fidelity;
- body/pose fidelity;
- subject/environment tonal hierarchy;
- believable depth;
- cinematic/low-light grade.

B owns:
- typography;
- page composition;
- paper/tape/collage when appropriate;
- editorial crop logic;
- copy;
- visual narrative.

## Hard boundary
B must not solve a layout problem by regenerating the person.

If B wants a second image containing the person:
1. crop from the same original/C master; or
2. use another user-supplied image confirmed to show the same person/session.

If neither is available, use environment/detail imagery instead of a synthetic lookalike.

## Re-grade limit
B may perform tiny integration adjustments so the page is coherent, but it may not overwrite C's skin tone, body/face identity, night-light logic, or subject hierarchy.
